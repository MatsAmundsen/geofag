# Kapittel 4: kontroll av skjulte figurer

Kontroll 6.–7. november 2026, Europe/Oslo.

4.10 er bygget med et foto av Geirangerfjorden tatt av Lukas Beck 29. juli 2025 (EXIF), lagt ut på Wikimedia Commons som eget verk med CC BY 4.0. Forrige forsøk mot originalfila ga HTTP 429. Denne gangen ga Commons API (prop=imageinfo med iiurlwidth) en miniatyr-URL. Miniatyren på 1920 px ble hentet fra upload.wikimedia.org med identifiserende User-Agent og svarte HTTP 200. Bildet er skalert til 1600 px og konvertert til WebP. Det er ikke beskåret eller retusjert, og bearbeidingen står i bildeteksten slik CC BY krever.

Bildet viser lite bosetting. Teksten sier det og viser til lokatorkartet 4.10a for steder og Åknes ved Sunnylvsfjorden. Ingen bølgehøyder er brukt. Kilde, lisens og kontrollsummer ligger i docs/geografi-kap4-skjulte-kilder.json.
