# Kapittel 8: kontroll av skjulte figurer

Kontroll 6.–7. november 2026, Europe/Oslo.

8.1 er bygget med Verdensbankens WDI-indikator SI.POV.DDAY, 3,00 dollar per dag i 2021-kjøpekraft, CC BY 4.0. Siste måleår 2015–2025 for 151 land, året står ved hvert land. Aggregater er fjernet med WDI-landmetadata. OWID-grafen som først ble hentet, viste den gamle 1,90-dollargrensen og ble ikke brukt.

8.5 og 8.7 bruker Global Carbon Budget 2025v15 via OWID, CC BY 4.0 både hos OWID og i opphavsmetadata. 8.5 viser 213 land i 2024. 8.7 viser Verden, Norge og Kina 1990–2024 med samme definisjon. Klassegrensene er egne og runde.

8.4 er en egen tegning med like store sektorer. Den viser bare de sju overskredne og to ikke overskredne grensene som PIK oppga 21. september 2026, ikke målte avstander.

8.6 er fortsatt skjult. Global Footprint Networks nyeste data er CC BY-SA 4.0, og vi fant ingen annen kontrollert kilde for økologisk fotavtrykk per land med åpen lisens uten deling på like vilkår. Den lokale fotavtrykkskalkulatoren fra forrige runde står.
