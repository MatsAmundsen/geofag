# Kildesjekk: Geologiske ressurser og Feltarbeid

Sjekket 2026-10-07. Hver rad i `KILDER.ressurser` og `KILDER.feltarbeid` er åpnet i denne runden (HTTP 200). Hver teksthenvisning i de to kapitlene har en rad her, og omvendt. Bokstavene følger tittel, alfabetisk med norsk sortering (`localeCompare` med `nb`), der samme forfatter og år går igjen. Listene er separate, så Feltarbeid har én NGU-side uten bokstav.

G1-biblioteket (g1-07, g1-08, g1-10 og liknende) lå ikke i arbeidsområdet. Ingen påstand er tatt derfra.

## Glosser, ikke nye målinger

I Feltarbeid er to setninger en lesning av målet, ikke en ny prosedyre: bearbeiding vil si å ordne observasjonene mot spørsmålet, og presentasjonen skal vise dataene og tolkningen. Udir definerer ikke de to verbene nærmere. Det er ikke lagt til GPS-nøyaktighet, koordinatsystem, feltbokkolonner eller en risikformel.

Forklaringsboksen «Hva betyr malm?» gjentar definisjonen som brødteksten siterer fra SNL (2024a). Boksen «Hva betyr feltarbeid?» gjentar innsamling av data og steinprøver, som brødteksten siterer fra SNL (2026).

Ingen figurer er montert. `PetroleumSystemDiagram`, `FraBergartTilBruddDiagram`, `OreFormationModel`, `PetroleumTrapModel`, `FieldworkIllustrationDiagram`, `FeltbokDiagram` og `FieldworkObservationModel` er ikke med.

## Ikke brukt

| Kilde eller påstand | Hvorfor den ikke står i kapitlene |
| --- | --- |
| Forvitring, sedimentære malmer, bauxitt | SNL forklarer sedimentær malm som kjemisk og mekanisk nedbrytning i jordoverflaten. Det er ikke forklart. Typen er bare nevnt som den tredje hovedtypen som ikke tas her. |
| Akvifer, grunnvannsspeil, porøsitet, permeabilitet | Skal ikke forklares. Grunnvann er nevnt som ressurs, med lenke til Vann og flom. |
| Isostasi og marin grense | Ikke tema på sidene som er brukt, og ikke forklart. |
| Konsentrasjonsfaktor, 60 ppm, 4 ppb, cut-off, London Metal Exchange | Sto i det gamle kapittelet. Ikke funnet på sidene som ble åpnet. |
| 1 % kobber = 10 kg per tonn | Setningen på NGUs kobberside er ødelagt i HTML-en og er ikke brukt. |
| Ekofisk 1969, 3000 m, 17 % til over 50 %, Draupne, 80–120 °C | Sto i det gamle kapittelet. Ikke funnet på SNL-siden om petroleum. |
| Sokkeldirektoratet, 15,6 milliarder Sm³, 66/17/2 felt, fondet i 2019 | Står inne i SNL-artikkelen som et øyeblikksbilde. Ikke brukt. Sokkeldirektoratet er ikke egen kilde. |
| Engebø, HR-2026-1360-A, Høyesterett | Ikke på NGU-, Udir- eller SNL-sidene som ble åpnet. |
| Direktoratet for mineralforvaltning og mineralstatistikk | Ikke åpnet. SNLs tall for blokkstein i 2007 er heller ikke brukt. |
| «Pukk er største uttak» | Ikke funnet på sidene som ble åpnet. Pukk er bare definert. |
| Fylkesregler for eksamen (Vestland, Rogaland) | Ikke NGU, Udir eller SNL. Ikke brukt. |
| HMS, risiko = fare × konsekvens, kvikkleire under marin grense | Står ikke i feltarbeidsmålet. Ikke lagt til. |
| Mobil-GPS noen meter, UTM, ETRS89, strøk og fall, Ott-flygel | Ikke funnet på sidene som ble åpnet. |
| Ferskvann som bærekraftsmål | Hører til Vann og flom. Ikke forklart her. |
